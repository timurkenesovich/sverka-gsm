# Бот водителя «Сверка ГСМ» — каркас (версия 2)

Telegram-бот для водителя: **фото одометра и чека → запись в журнал машины**.
Владелец раз в месяц получает от бота два CSV-файла — «путевые листы» и «заправки по чекам» — и загружает их
на страницу «Сверка ГСМ» вместе с выгрузкой GPS.

Это каркас: бот не развёрнут, распознавания цифр на фото нет (водитель вводит число сам, фото хранится как подтверждение).

## Как работает

| Кто | Действие |
|---|---|
| Водитель | `/start` → выбирает свою машину |
| Водитель | присылает фото → «Одометр» → вводит показание (бот не даст ввести меньше прошлого) |
| Водитель | присылает фото → «Чек АЗС» → вводит литры и сумму |
| Владелец | `/export 2026-10` → получает `путевые_листы_2026-10.csv` и `заправки_по_чекам_2026-10.csv` |
| Любой | `/myid` → узнать свой Telegram ID (нужен владельцу для `OWNER_IDS`) |

Путевой лист за день собирается так: первое фото одометра за день — выезд, последнее — возврат.
Если за день одно фото, выездом считается прошлое показание.

Журнал хранится в файле `data/journal.csv` на том компьютере или сервере, где запущен бот.

## Запуск (для того, кто будет разворачивать)

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите токен.
2. Установите Python 3.10+ и библиотеку:
   ```bash
   pip install -r bot/requirements.txt
   ```
3. Задайте настройки и запустите:
   ```bash
   cd bot
   BOT_TOKEN=123:ABC CARS="123 ABC 02,456 DEF 02" OWNER_IDS=111111111 python bot.py
   ```
   - `CARS` — госномера через запятую (как в справочнике на странице);
   - `OWNER_IDS` — Telegram ID владельцев через запятую;
   - `JOURNAL` — путь к журналу (по умолчанию `data/journal.csv`).

Тесты журнала: `python -m unittest bot/test_journal.py`
