# Сверка ГСМ — проверка за вечер

Одна веб-страница для владельцев и управляющих автопарков (5–50 машин): загружаете три выгрузки за месяц и сразу видите,
**где расход топлива не сходится с пробегом** и **где топливные карты «гуляют» между машинами**.

**Страница:** https://timurkenesovich.github.io/sverka-gsm/
(заработает после включения GitHub Pages — см. «Публикация» ниже)

Пример с готовыми данными: https://timurkenesovich.github.io/sverka-gsm/?demo

> 🔒 **Данные никуда не отправляются.** Все расчёты идут в браузере на вашем компьютере. Сервера нет,
> регистрации нет, в коде нет ни одного сетевого запроса. Страница работает и без интернета.

---

## Как загрузить свои данные

1. Откройте страницу и нажмите **«Загрузить свои данные»** (или сначала **«Попробовать на примере»**, чтобы посмотреть, как это выглядит).
2. Перетащите файлы в поля (или нажмите на поле и выберите файл). Подходят **Excel (XLSX, XLS)** и **CSV**.

   | Файл | Какие колонки нужны |
   |---|---|
   | **GPS** | госномер машины, дата, пробег за день (км) |
   | **Путевые листы** | госномер, водитель, дата, одометр на выезде, одометр на возврате |
   | **АЗС по топливным картам** | номер карты, дата и время, АЗС, литры, сумма. Если АЗС пишет госномер — тоже пригодится |
   | **Справочник** (необязательно) | госномер, норма л/100 км, закреплённые карты, резервные карты, остаток на начало/конец |

3. Если программа не узнала колонку (например, у вас она называется «Отпущено»), откройте
   **«Какая колонка что означает»** под файлом и выберите нужную в выпадающем списке.
4. В разделе **«Справочник машин»** машины из файлов появятся сами. Впишите **норму расхода** и **номера карт**
   (несколько — через запятую). Остатки в баке на начало и конец месяца — если не знаете, оставьте 0.
5. Нажмите **«Проверить»**.

Советы:
- Даты понимаются в видах `31.10.2026`, `31.10.26`, `2026-10-31`, с временем и без. Числа — с запятой или точкой (`45,3`).
- Госномера сравниваются без учёта пробелов и русских/латинских букв: `123 АВС 02` = `123ABC02`.
- CSV из 1С в кодировке Windows-1251 тоже читается.
- Чтобы увидеть, как должны выглядеть файлы, скачайте примеры — ссылки под полями загрузки.

## Что считает программа

- **Возможный слив.** Расчётный пробег по заправкам = (остаток на начало + литры − остаток на конец) ÷ норма × 100.
  Если он больше пробега по GPS сверх допуска (по умолчанию 5%), разница показывается в литрах и тенге.
- **GPS против путевых листов.** Расхождение пробега по машине в %. Ниже порога погрешности GPS (±5%) не подсвечивается.
  Если по путевым больше, чем по GPS, — возможна подкрутка одометра. Ещё проверяются разрывы одометра между путевыми листами.
- **«Чьи карты?»** Каждая карта — отдельный счёт: сколько литров и в какие машины. Заправки машин картами,
  которые за ними не закреплены, и заправки в дни, когда машина по GPS стояла.
- **Итог.** Сколько литров и тенге не объяснено пробегом за месяц, по машинам и в целом; светофор и ТОП-5.
- **Отчёт.** Выгрузка в Excel (5 листов) и печать / PDF через печать браузера.

Пороги меняются в блоке «Пороги проверки». Результат — повод разобраться, а не доказательство: причиной может быть
неверная норма, зимний режим, простой с работающим двигателем или сбой GPS.

## Демо-данные

Кнопка «Попробовать на примере» загружает выдуманный автопарк: 12 машин, октябрь 2026. Номера (`ДЕМО 01`…), карты
(`DEMO-…`), водители и АЗС вымышлены. В примере спрятаны три нарушения:

| Машина | Нарушение | Как видно |
|---|---|---|
| ДЕМО 03 | слив — вечерние заправки «в канистру» | +37% топлива к норме, ≈ 52 тыс. ₸ |
| ДЕМО 09 → ДЕМО 05 | чужая карта — машина в ремонте, её картой заправляют другую | раздел «Чьи карты?» |
| ДЕМО 07 | подкрученный одометр — в путевых на 20% больше, чем по GPS | расхождение путевых и GPS, +20% топлива |

## Публикация (GitHub Pages)

Один раз:
1. Слейте ветку с работой в `main`.
2. В репозитории на GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка **`main`**, папка **`/ (root)`**, нажать **Save**.
3. Через 1–2 минуты страница откроется по адресу https://timurkenesovich.github.io/sverka-gsm/

Дальше каждое изменение в `main` публикуется само.

## Для разработчика

- Чистый статический сайт: `index.html`, `css/`, `js/`. Сборки нет, библиотеки лежат в `vendor/`
  ([SheetJS](https://sheetjs.com/) 0.18.5 для Excel, [Chart.js](https://www.chartjs.org/) 4.4.1 для графиков).
- `js/core.js` — все расчёты (без браузерных зависимостей), `js/demo.js` — генератор примера, `js/app.js` — интерфейс.
- Тесты: `node tests/run.js` (Node.js 18+, без установки пакетов). Проверяют разбор дат и чисел, сопоставление колонок
  и то, что три заложенных нарушения находятся, а 8 честных машин остаются зелёными. Тесты запускаются на GitHub
  при каждом пуше (`.github/workflows/tests.yml`).
- Открыть локально: просто откройте `index.html` в Chrome.
